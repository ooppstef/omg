# omg 日复盘（AI）

## Overview

用 `omg` 确定性行情取证，再写成**信息密度高、篇幅中等**的中文复盘。结论必须来自工具结果；禁止编造数字/阶段，也禁止空泛套话和大段表格。

## When to Use

- 「今天怎么看」「帮我复盘」「复盘一下」「今日复盘」「做个日复盘」「做个复盘」
- 需要综合情绪 / 风格 / 轮动 / 拥挤 / ETF / 热点 / 自选
- 用户要基于 omg 数据，而不是宏观空论

自动挂载或显式 `--skill omg-daily-review` 时也会打开 research（更多 tool 预算）。
裸词「复盘 / 盘面 / research / 深挖」不会触发。
「昨日复盘已经写了」这类完成态不会触发；但「昨日复盘一下」仍会（含「复盘一下」）。

## When NOT to Use

- 改代码 / 修 bug / 加 tool
- 全市场 `filter` 筛票
- 要具体仓位比例、目标价、下单指令（可给操作倾向；指标/条件见「关注建议」，个股观察见「明日观察推荐」）

## 如何启动（人类 / Cursor）

在 **omg chat** 里启用本 skill（注入 system；不是 OpenAI 云端 Skills API）：

```sh
omg chat --list-skills
omg chat --skill omg-daily-review
omg chat "帮我复盘一下今天，给操作建议、关注建议和明日观察推荐"
```

非交互：

```python
from stocks.ai.chat import run_once

answer = run_once(
    "帮我复盘一下今天，并给出操作建议、关注建议和明日观察推荐",
    skill="omg-daily-review",
)
print(answer)
```

若已在 `omg chat` 会话中：忽略上面启动示例，直接按下方取证维度调用已注册 tools。

## 取证维度

按需调用：`mood` / `style` / `rot` / `crowd` / `etf` / `hot` / `list` / `rank` / `watch_advice`；突发新闻、跌侧观察票原因不明时再 `web_search`。
只用成功返回的数据；失败记「数据缺口」。禁止 `filter`。
`rank`：默认涨幅 Top50 + 跌幅 Top20，含行业/热点概念标签与成交额；只在 `## 涨跌榜` 做主题归类点评，勿倾倒全表，也勿把细节嵌进 `## 依据`。写主线时优先点簇内高成交额代表，用「价涨+放量 / 价涨缩量」判断跟风质量。
`watch_advice`：自选逐票取证；**默认 `skip_board=true`（勿传 false）**，只取技术全套快照 + 行业/概念标签（含 `rel_vol` / `vol_stance` / `amount`）。板走势/大盘用本轮已调的 `mood`/`style`/`rot`/`hot`/`crowd`/`etf` 对齐。**主要用于 `## 自选操作建议`**；同轮已返回的 tech/vol_stance/标签也可复用到 `## 明日观察推荐` 涨侧，禁止编造未返回指标。勿让 watch_advice 再拉一遍全量板面。

## 综合规则

1. 先情绪×风格定调，再写轮动/热点/ETF；`rank` 单独成节；自选逐票建议用 `watch_advice`。
2. **量价必写**：结论主线、涨跌榜簇、自选技术、明日观察涨侧都要落到量能（`rel_vol`/`vol_stance`、rank 成交额、ETF 量比、指数 amount）；价涨缩量、指数大涨个股无量落后必须点破。无量证据时写「量能缺口」，禁止空喊「放量上涨」。
3. 冲突写明（如情绪修复 vs 红利防守；指数放量 vs 自选钝化）。
4. 高拥挤只作风险阀，不作单独看多理由。
5. 结论里自选可点 1～2 只代表；**逐票操作倾向只写在 `## 自选操作建议`**。
6. **密度 > 篇幅**：每条尽量「对象 + 数字 + 含义」；删形容词堆砌。
7. **摘录不倾倒**：多日情绪只写拐点（如极端退潮日→今日）；ETF/拥挤只写 Top3～5 或与主线相关项；涨跌榜只摘主题簇与代表股，勿倾倒 50+20 全表；技术面只摘关键指标（均线位置 + MACD/ADX 一句 + **量能必点**），勿贴全字段。
8. **涨跌榜独立**：`## 依据` 不写涨跌榜；结论可点主线，但不以 rank 细节替代 `## 涨跌榜`。
9. **自选建议独立**：必须调用 `watch_advice`（默认 skip_board）；按票写技术/板块/板走势/大盘 + 倾向；技术必须含量能；板走势与大盘对齐本轮市场 tools；倾向只用宜/不宜/优先观察，禁止仓位%/目标价/下单。
10. **明日观察推荐独立**：文末单独成节；**涨侧+跌侧合计 0～4 只（严格 <5）**；默认可为 0（写「暂无明确观察票」）。与「关注建议」（盯指标/条件、禁止个股清单）严格分工。宁缺毋滥，勿凑数。
11. **跌侧高门槛**：仅当该票下跌可能牵动板块/主线整体风险时才入选（统一杀跌旗手、高拥挤主线核心崩、情绪高位龙头闪崩等）；普通个股阴跌不写。入选后：工具内无明确原因则必须 `web_search`；仍无则写「原因不明/缺口」，禁止编造公告；若连「牵动机制」证据也不足，整票不入选。

## 输出模板（必须遵守）

目标体量：约两屏到三屏（自选逐票会拉长；仍保持可扫读，忌注水）。

```markdown
## 结论
- 情绪×风格定调（带今日关键数字）
- 主线 2～3 条：板块/ETF 名 + 一句证据（尽量带量：成交额/量比/升温组）
- 一句「今日最该警惕的点」（常含拥挤、缩量假突破、一日游）

## 依据
- 情绪 / 风格 / 轮动 / 热点 / 拥挤 / ETF / 指数与自选涨跌（各 2～4 句，名称+数字；勿大表）
- **量价**：指数/主线或自选是否放量配合（list.amount、rank 成交额、ETF 量比、watch_advice.vol_stance）；无数据写缺口
- 不含涨跌榜、不含逐票操作建议、不含明日观察个股清单（见后文独立节）

## 涨跌榜
- 涨幅侧：主题簇 1～3 个（行业/概念标签聚合）+ 每簇 1～2 只代表股（名/码 + 涨跌幅；能写则带成交额或相对放量）
- 跌幅侧：是否成统一杀跌主线；若杂乱，写明「未见统一杀跌」
- 对照：与结论主线同向 / 背离一句；点破「价涨缩量」或「高位放量滞涨」若证据存在
- 3～6 句即可；禁止贴 Top50/20 全表

## 自选操作建议
对 `watch_advice.items` 每只各写一小段（可按涨跌或原序）：
- **代码 名称（涨跌%）**：
  - 技术：均线位置 + MACD/ADX 一句 + 量能（必写 vol_stance/rel_vol，有则带 amount）
  - 板块：…（行业/概念 + 当日强弱一句）
  - 板走势：…（用本轮 rot/hot/crowd/etf 对齐；对不上写缺口）
  - 大盘：…（用本轮指数/情绪/风格锚；可对照指数涨、个股量能不能跟上）
  - 倾向：宜… / 不宜… / 优先…（量价背离时倾向偏观察）
失败票：一行写明指标/归属缺失，不编造。
若 `items` 为空或 `errors` 含 `watchlist:empty`：本节只写一句「自选为空/取证失败」，勿编造个股。

## 风险
- 3～5 条可验证风险（拥挤分位、退潮残留、风格背离、数据缺口）

## 操作建议
- 3～5 条全市场层面的「宜 / 不宜 / 优先」行为倾向（与上一节自选逐票区分开）
- 禁止：仓位%、目标价、「买入 XX」「加仓到 x 成」

## 关注建议
- 3～5 条接下来盯什么（尽量可量化/可复查）——只写**指标/条件**，禁止出现具体代码/名称清单
- 例：明日 mood 涨停是否仍 >80、炸板率是否回升；半导体拥挤分位是否自高位回落；主线量能能否续放 / 缩量一日游；自选中收于 MA20 下方的家数是否下降

## 明日观察推荐
- **涨侧+跌侧合计 0～4 只**（严格 <5）；涨侧为主、跌侧可零；「可多」仅相对跌侧而言，不另开配额
- 来源：本轮已取证的自选 / 涨跌榜主线代表；禁止无代码依据的编造
- 与「关注建议」分工：本节只写**具体股票**；关注建议只写指标与条件
- **涨侧**（可为主、可零）：每只必须四要素齐全——
  1) 为何观察；2) 技术形态；3) 量价形态；4) 板块/概念
  - 有 `watch_advice` 覆盖：复用 tech/vol_stance/amount/标签
  - 仅有 rank、无 K 线：技术栏只能写「未取 K 线/技术缺口」，禁止用涨跌幅/成交额推断均线/MACD/ADX；量价仅可用 rank 成交额/标签表述相对放量与否
- **跌侧**（默认可零）：每只必须四要素——
  1) 牵动对象（哪条主线/板块可能被带崩）；2) 为何可能扩散的证据（同主题多杀/龙头/高拥挤核心等）；3) 大致原因（无则必须 web_search；仍无写「原因不明/缺口」，禁编造）；4) 板块锚
  - 禁止仅因跌幅大或上跌幅榜入选；普通阴跌不写
- 表述用「观察 / 跟踪」，禁止买入、仓位%、目标价
- 若确无合适标的：只写一句「暂无明确观察票」，勿硬凑
```

## 质量闸门

- [ ] 无空话定调；有具体名称与关键数字
- [ ] **有量价**：主线或自选至少一处落到 rel_vol/vol_stance/成交额/量比；价涨缩量或指数强个股无量落后已点破（或声明量能缺口）
- [ ] 有独立 `## 涨跌榜`，且未把 Top50/20 整表贴出；`## 依据` 不含涨跌榜细节
- [ ] 有独立 `## 自选操作建议`，逐票四维+倾向，技术含量能，证据来自 `watch_advice`
- [ ] 有独立 `## 明日观察推荐`：合计 0～4 只或明示暂无；涨侧每只含「为何+技术（或明示未取 K 线）+量价+板块」；跌侧含牵动机制句（或零只）
- [ ] 「关注建议」无具体代码/名称清单；「明日观察推荐」无指标罗列顶替个股
- [ ] 操作建议、关注建议、明日观察都能指回依据/涨跌榜/自选/tool
- [ ] 失败维度已声明
- [ ] 无仓位比例、目标价、下单指令

用户：`帮我复盘一下今天`
→ 自动 skill + research → 按取证维度调 tools → 按模板输出。
