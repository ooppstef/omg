# omg 日复盘（AI）

## Overview

用 `omg` 确定性行情取证，再写成**信息密度高、篇幅中等**的中文复盘。结论必须来自工具结果；禁止编造数字/阶段，也禁止空泛套话和大段表格。

## When to Use

- 「今天怎么看」「帮我复盘」「复盘一下」「今日复盘」「做个日复盘」「做个复盘」
- 需要综合情绪 / 风格 / 轮动 / 拥挤 / ETF / 热点 / 自选
- 用户要基于 omg 数据，而不是宏观空论

自动挂载或显式 `--skill omg-daily-review` 时也会打开 research（更多 tool 预算）。
裸词「复盘 / 盘面 / research / 深挖」不会触发。
「昨日复盘已经写了」这类完成态不会触发；但「昨日复盘一下」仍会（含「复盘一下」）。

## When NOT to Use

- 改代码 / 修 bug / 加 tool
- 全市场 `filter` 筛票
- 要具体仓位比例、目标价、下单指令（可给操作倾向与关注清单，见模板）

## 如何启动（人类 / Cursor）

在 **omg chat** 里启用本 skill（注入 system；不是 OpenAI 云端 Skills API）：

```sh
omg chat --list-skills
omg chat --skill omg-daily-review
omg chat "帮我复盘一下今天，给操作建议和关注建议"
```

非交互：

```python
from stocks.ai.chat import run_once

answer = run_once(
    "帮我复盘一下今天，并给出操作建议与关注建议",
    skill="omg-daily-review",
)
print(answer)
```

若已在 `omg chat` 会话中：忽略上面启动示例，直接按下方取证维度调用已注册 tools。

## 取证维度

按需调用：`mood` / `style` / `rot` / `crowd` / `etf` / `hot` / `list` / `rank` / `watch_advice`；突发新闻再 `web_search`。
只用成功返回的数据；失败记「数据缺口」。禁止 `filter`。
`rank`：默认涨幅 Top50 + 跌幅 Top20，含行业/热点概念标签；只在 `## 涨跌榜` 做主题归类点评，勿倾倒全表，也勿把细节嵌进 `## 依据`。
`watch_advice`：自选逐票取证（技术全套快照 + 行业/概念 + 板走势对齐 + 大盘锚）；只在 `## 自选操作建议` 使用，禁止编造未返回的指标。依据节仍调 `mood`/`style`/`rot`/`hot`/`crowd`/`etf` 写市场叙事（与 watch_advice 内部对齐可并存）。

## 综合规则

1. 先情绪×风格定调，再写轮动/热点/ETF；`rank` 单独成节；自选逐票建议用 `watch_advice`。
2. 冲突写明（如情绪修复 vs 红利防守）。
3. 高拥挤只作风险阀，不作单独看多理由。
4. 结论里自选可点 1～2 只代表；**逐票操作倾向只写在 `## 自选操作建议`**。
5. **密度 > 篇幅**：每条尽量「对象 + 数字 + 含义」；删形容词堆砌。
6. **摘录不倾倒**：多日情绪只写拐点（如极端退潮日→今日）；ETF/拥挤只写 Top3～5 或与主线相关项；涨跌榜只摘主题簇与代表股，勿倾倒 50+20 全表；技术面只摘关键指标，勿贴全字段。
7. **涨跌榜独立**：`## 依据` 不写涨跌榜；结论可点主线，但不以 rank 细节替代 `## 涨跌榜`。
8. **自选建议独立**：必须调用 `watch_advice`；按票写技术/板块/板走势/大盘 + 倾向；倾向只用宜/不宜/优先观察，禁止仓位%/目标价/下单。

## 输出模板（必须遵守）

目标体量：约两屏到三屏（自选逐票会拉长；仍保持可扫读，忌注水）。

```markdown
## 结论
- 情绪×风格定调（带今日关键数字）
- 主线 2～3 条：板块/ETF 名 + 一句证据
- 一句「今日最该警惕的点」

## 依据
- 情绪 / 风格 / 轮动 / 热点 / 拥挤 / ETF / 指数与自选涨跌（各 2～4 句，名称+数字；勿大表）
- 不含涨跌榜、不含逐票操作建议（见后两节）

## 涨跌榜
- 涨幅侧：主题簇 1～3 个（行业/概念标签聚合）+ 每簇 1～2 只代表股（名/码 + 涨跌幅）
- 跌幅侧：是否成统一杀跌主线；若杂乱，写明「未见统一杀跌」
- 对照：与结论主线同向 / 背离一句
- 3～6 句即可；禁止贴 Top50/20 全表

## 自选操作建议
对 `watch_advice.items` 每只各写一小段（可按涨跌或原序）：
- **代码 名称（涨跌%）**：
  - 技术：…
  - 板块：…（行业/概念 + 当日强弱一句）
  - 板走势：…（rot/hot/crowd/etf 对齐；对不上写缺口）
  - 大盘：…（指数/情绪/风格锚）
  - 倾向：宜… / 不宜… / 优先…
失败票：一行写明指标/归属缺失，不编造。

## 风险
- 3～5 条可验证风险（拥挤分位、退潮残留、风格背离、数据缺口）

## 操作建议
- 3～5 条全市场层面的「宜 / 不宜 / 优先」行为倾向（与上一节自选逐票区分开）
- 禁止：仓位%、目标价、「买入 XX」「加仓到 x 成」

## 关注建议
- 3～5 条接下来盯什么（尽量可量化/可复查）
- 例：明日 mood 涨停/跌停与炸板率；半导体拥挤分位是否回落；自选中技术面背离品种
```

## 质量闸门

- [ ] 无空话定调；有具体名称与关键数字
- [ ] 有独立 `## 涨跌榜`，且未把 Top50/20 整表贴出；`## 依据` 不含涨跌榜细节
- [ ] 有独立 `## 自选操作建议`，逐票四维+倾向，证据来自 `watch_advice`
- [ ] 操作建议、关注建议都能指回依据/涨跌榜/自选/tool
- [ ] 失败维度已声明
- [ ] 无仓位比例、目标价、下单指令

## 示例触发

用户：`帮我复盘一下今天`
→ 自动 skill + research → 按取证维度调 tools → 按模板输出。
