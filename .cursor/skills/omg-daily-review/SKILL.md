# omg 日复盘（AI）

## Overview

用 `omg` 确定性行情取证，再写成**信息密度高、篇幅中等**的中文复盘。结论必须来自工具结果；禁止编造数字/阶段，也禁止空泛套话和大段表格。工具里的阶段、状态和分数是**描述性启发式规则标签**，不是未来收益概率或已经回测验证的 alpha。

## When to Use

- 「今天怎么看」「帮我复盘」「复盘一下」「今日复盘」「做个日复盘」「做个复盘」
- 需要综合情绪 / 风格 / 轮动 / 拥挤 / ETF / 热点 / **近期强势** / 自选
- 用户要基于 omg 数据，而不是宏观空论

自动挂载或显式 `--skill omg-daily-review` 时也会打开 research（更多 tool 预算）。
裸词「复盘 / 盘面 / research / 深挖」不会触发。
「昨日复盘已经写了」这类完成态不会触发；但「昨日复盘一下」仍会（含「复盘一下」）。

## When NOT to Use

- 改代码 / 修 bug / 加 tool
- 全市场 `filter` 筛票
- 要具体仓位比例、目标价、下单指令（可给操作倾向；指标/条件见「关注建议」，个股观察见「底部启动 / 推荐关注」）

## 如何启动（人类 / Cursor）

在 **omg chat** 里启用本 skill（注入 system；不是 OpenAI 云端 Skills API）：

```sh
omg chat --list-skills
omg chat --skill omg-daily-review
omg chat "帮我复盘一下今天，给操作建议、关注建议、底部启动和推荐关注"
```

非交互：

```python
from stocks.ai.chat import run_once

answer = run_once(
    "帮我复盘一下今天，并给出操作建议、关注建议、底部启动和推荐关注",
    skill="omg-daily-review",
)
print(answer)
```

若已在 `omg chat` 会话中：忽略上面启动示例，直接按下方取证维度调用已注册 tools。

## 取证维度

按需调用：`mood` / `style` / `rot` / `crowd` / `etf` / `hot` / `strength` / `list` / `rank` / `watch_advice`；突发新闻、跌侧观察票原因不明、**以及任何要写「低吸/关注」的票的逻辑面核实**，再临时 `web_search`（只认最新资料）。
只用成功返回的数据；失败记「数据缺口」。禁止 `filter`。
`strength`（**`## 近期强势` 的主证据，也用于 `## 结论` 的定调与 `## 底部启动` / `## 推荐关注` 的选票**）：一次取证给四层——① `regime` 市场结构（普涨扩散 / 板块轮动 / 主题抱团 / 权重·红利抱团 / 普跌无主线 / 结构不明，含 `reasons` 与 `metrics`：5 日上涨概念占比、Top十分位−中位数、龙头独拉占比、涨停行业 HHI 等）；② `themes` 主题线强度榜——由高重叠概念 + 行业板块按成分股 Jaccard 合并，**可跨行业**（抱团线常横跨多个行业，这正是它的口径），每条含 `picked_by`（概念强度 / 行业强度 / 启动分）与退潮迹象 `fade_signals` + `s_risk`，配套 `boards.concept` / `boards.industry` / `boards.weak_concept`（退潮侧）；③ `stocks` 个股强度榜（3/5/10/60 日涨幅、量比、相对沪深300 超额、日线技术面 `tech` / `tech_notes`、剩余空间 `space`、回落性质 `pullback`、操作口径 `action`）；④ `bottom` **底部启动榜**——位置还低（5/10/60 日涨幅未超阈值）+ 当日/3 日转强 + 放量，字段与 `stocks` 同形状（已走强的票多在异动口径内没 b 点，可参与的多在这一层）。
引用口径：`score` / `turn_score` 是**同一截面内的分位（0～100）**，不是上涨概率或预测；`quote_trade_date` / `quote_timestamp` 由行情时间戳推导，是**真实报价交易日**，可直接用于时点对齐（`as_of_dates` 另含涨停池等来源日期）。主题成员统计是**强势成员口径**（板块按 5 日涨幅排序首页 ≤100 只），板块**真实宽度**只看该板块自己的 `breadth`；个股归因 `attribution`（theme / stock 两段，**市场因素只在顶层 `market.context` 给一次**）与 `tech_notes` 是可直接引用的事实句（超额、宽度、量比、涨停数、均线位置、MACD/ADX、`rel_vol`）。`themes[].s_risk` / `fade_signals` 是退潮迹象（阶段回落 / 当日转跌 / 承接转弱）的计数等级，只写「可能在 S 点区域」；`stocks[].space` 是**近似**异动口径（以沪深300 代对应指数：主板 3 日 20%、创业板/科创板 30%，10 日严重异常波动 ≈100%）+ 涨停池连板高度，只提示剩余空间；`stocks[].action`（低吸 / 追高 / 不参与）是 regime × stage × 空间 × 所在线 `s_risk` 的规则映射，**非建议、不给点位**（`action_notes` 为空 = 默认口径：未退潮、空间未受限、环境未扩散 → 回踩低吸）。`boards.weak_concept` 只能写相对弱势，不能据此断言反转；`meta.n_concepts_excluded` 表示已剔除的伪概念（昨日连板、财报事件、指数成分等）。**选股与主题线已屏蔽**：ST/退市、北交所（非 A 股代码前缀）、红利类概念（`_EXCLUDE_CONCEPT_KEYWORDS`，如 红利股）——`boards.*` 仍保留原始截面，具体缺口看 `notes`。`bottom[]` 的排序键是 `launch.points` **启动标志**加权分（满分 20）——**量能** 3 条（量能突变 rv20≥2、短周期放量 rel_vol≥1.5、MFI≥60）、**资金** 1 条（主力净流入>0 且占比≥3%）、**形态** 5 条（刚站上 MA20 0～12%、贴近/站上 MA60、收在日内高位、MACD 柱翻红、均线粘合 ≤3%）各 2 分，价格（大阳 ≥5%）与方向（+DI > −DI）各 1 分；`bottom[].score` 只是量价分位（粗排与同分次序，**与 `stocks[].score` 的强势分位口径不同**）。选票口径是「5/10/60 日涨幅未超阈值」的低位池，不是「跌得多的票」。`stocks[].main_inflow` / `main_inflow_pct` 是东财当日**个股主力净流入**（元 / 占成交额比），只覆盖个股。
禁止把 `score` 写成概率或「必涨」；主题名可用，但每条必须同时挂 ≥2 个数字。
`rank`：默认涨幅 Top50 + 跌幅 Top20，含行业/热点概念标签与绝对成交额；源接口不提供行情所属交易日，只有 `observed_at`，因此必须写明「观察时点、交易日未验证」。只在 `## 涨跌榜` 做主题归类点评，勿倾倒全表，也勿把细节嵌进 `## 依据`。可写「截面成交额较高」，但**绝对成交额不能证明放量或缩量**；只有带历史基准的 `rel_vol` / `vol_stance` / ETF `vol_ratio` 才能这样表述。rank 是两端截面样本，不能代替全市场宽度。
`watch_advice`：自选逐票取证；**默认 `skip_board=true`（勿传 false）**，只取技术全套快照 + 行业/概念标签（含 `rel_vol` / `vol_stance` / `amount`）。板走势/大盘用本轮已调的 `mood`/`style`/`rot`/`hot`/`crowd`/`etf`/`strength` 对齐。**主要用于 `## 自选操作建议`**；同轮已返回的 tech/vol_stance/标签也可复用到 `## 推荐关注` 涨侧，禁止编造未返回指标。勿让 watch_advice 再拉一遍全量板面。
`etf`：除状态/量比外，含当日 `session_path`（`path_label` / `open_pct` / `close_vs_open` / 上下影）。主线 ETF **必须写日内路径**；`path_status` 为 `ohl_missing` / `ohl_inconsistent` 时声明路径缺口。「高开低走 / 冲高回落」时不得仅因收盘涨幅写成趋势确认日。

## 证据边界

1. **先对齐时点**：逐维检查 `as_of` / `as_of_dates` / `trade_date` / 实时时间；日期不同就分别标注，禁止把旧数据拼成同一交易日结论。`observed_at` 只是请求观察时间，不能替代行情所属交易日；盘中数据须写「盘中」，不能冒充收盘。
2. **分三层写**：原始数字是事实；mood/style/rot/ETF 状态与分数是规则标签；“主线、扩散、风险”是综合推断。不得把后两者写成客观事实或预测概率。
3. **主线至少两类独立证据**：例如轮动/热点之一 + 成分宽度、ETF、涨跌榜成簇或风格之一。仅 rank 成簇、单个热榜名次或单只大涨都不足以确认主线。
4. **不强迫结论**：证据冲突、关键维度失败或日期错位时降低置信度；可以给 0 条主线、0 只观察票，并明确缺口。
5. **不偷换因果**：新闻与涨跌同时出现只写「可能催化/相关事件」；除非公司公告或权威一手材料明确因果，否则禁止写成确定原因。
6. **拥挤只描述相对交易份额**：高分位不是看空概率，也不自动意味着反转；需与价格、轮动或量价冲突共同解释。`amount_source=ths_same_name_proxy` 表示同名代理口径，必须标注并降低权重。
7. **strength 优先级**：`regime` 是规则判定标签——先复述 `reasons`/`metrics` 里的数字，再写「结构偏向 X」；`score`/`turn_score` 是**截面分位**，不得写成概率或「强度高就该涨」；主题线是「成分股重叠合并」的结果，可以直接命名，但不得让读者以为是官方板块指数；主题成员数受 100 只首页限制，宽度结论只引用板块自身 `breadth`。`s_risk` / `space` / `action` 同理只是规则标签，不得写成点位、买卖建议或概率。
8. **归因只写同向/可能相关**：`strength` 的 attribution 是事实句，不是原因；把「市场因素 → 主题 → 个股」写成可能相关的同向证据链，禁止因果断言（同 `web_search` 规则）。
9. **技术面回踩 ≠ 低吸理由**：`stocks[].pullback` 只判结构（缩量回踩 / 放量调整 / 技术面走坏）；「为什么跌、逻辑还在不在」必须**临时 `web_search`** 取**最新**消息面/公告/基本面，并写明来源与时点。本地与缓存资料会过期——过期资料不如不用；拿不到最新逻辑证据时按 **A 杀风险**对待，不得写成低吸。
10. **体系缺口要声明，不要用缺口维度下结论**（当前已知缺口）：① **资金面**——只有个股主力净流入（`main_inflow`），**行业资金流、龙虎榜席位、北向、融资融券均未覆盖**；② **情绪细节**——晋级率（1 进 2 / 2 进 3）、连板天梯、封板质量、涨停原因归类未覆盖（已有涨停/跌停/炸板/炸板率/高度/首板占比/溢价）；③ **事件日历**——业绩披露、解禁、减持、重组进展需临时 `web_search`；④ **跨日连续性**——`strength` 是每日独立截面（无历史分位），跨日对比只能用 `mood` 多日 + 当日多周期涨幅；⑤ **异动口径**——未纳入「换手率类」异动标准；⑥ **持仓管理**——只做观察/跟踪，不给仓位与纪律（见「When NOT to Use」）。这些维度缺证据时写「缺口」，禁止用涨跌幅或成交额代替。

## 综合规则

1. 先情绪×风格×`strength.regime` 定调，再写轮动/热点/ETF 与近期强势；`rank` 单独成节；自选逐票建议用 `watch_advice`。
2. **量价必写**：相对量能只用 `rel_vol` / `vol_stance` / ETF `vol_ratio`；rank/list 的 `amount` 只能写当日绝对成交额或成交活跃度。价涨缩量、个股量能落后只在有历史基准时点破；无相对量证据时写「量能缺口」，禁止空喊「放量上涨」。
3. 冲突写明（如情绪修复 vs 红利防守；指数走强 vs 自选钝化）。
4. 高拥挤只作风险阀，不作单独看多理由。
5. 结论里自选可点 1～2 只代表；**逐票操作倾向只写在 `## 自选操作建议`**。
6. **密度 > 篇幅**：每条尽量「对象 + 数字 + 含义」；删形容词堆砌。
7. **摘录不倾倒**：多日情绪只写拐点（如极端退潮日→今日）；ETF/拥挤只写 Top3～5 或与主线相关项；涨跌榜只摘主题簇与代表股，勿倾倒 50+20 全表；技术面只摘关键指标（均线位置 + MACD/ADX 一句 + **量能必点**），勿贴全字段。
8. **涨跌榜独立**：`## 依据` 不写涨跌榜；结论可点主线，但不以 rank 细节替代 `## 涨跌榜`。
9. **自选建议独立**：必须调用 `watch_advice`（默认 skip_board）；按票写技术/板块/板走势/大盘 + 倾向；技术必须含量能；板走势与大盘对齐本轮市场 tools；倾向只用宜/不宜/优先观察，禁止仓位%/目标价/下单。
10. **底部启动与推荐关注独立**：文末两个模块，**两节合计 0～10 只（严格 ≤10）**，对象都是**具体票**（板块/线只作理由，禁止「只跟线不跟票」）。`## 底部启动` 只写 `strength.bottom`（按 `launch` 启动标志分排序，≤10 只）；`## 推荐关注` 写其余观察票（自选 / 强势「等回踩」票 / 涨跌榜主线代表 / 跌侧高门槛），**两节不重复同一只票**。默认可为 0（写「暂无」）。与 `## 关注建议`（只写指标/条件、禁止个股清单）严格分工。宁缺毋滥，勿凑数。
11. **跌侧高门槛**：仅当该票下跌可能牵动板块/主线整体风险时才入选（统一杀跌旗手、高拥挤主线核心崩、情绪高位龙头闪崩等）；普通个股阴跌不写。入选后：工具内无明确原因则必须 `web_search`；仍无则写「原因不明/缺口」，禁止编造公告；若连「牵动机制」证据也不足，整票不入选。
12. **近期强势独立**：`## 近期强势` 只写**近 3～10 日**走强的板块与个股（证据来自 `strength`），与 `## 涨跌榜`（当日两极截面）、`## 底部启动` / `## 推荐关注`（具体观察票）分工；**底部启动（`strength.bottom`）不进本节，写进 `## 底部启动`**。每条必须挂数字：相对沪深300 超额 pp / 宽度 / 涨停数 / 量比 / `rel_vol` / ADX·MACD 之一；归因按「市场因素 → 主题 → 个股」三段各一句，只写同向或可能相关，禁因果断言。**强 ≠ 还能买**：主题线须答「仍在加速 / 已现退潮迹象（S 风险，引 `stage` 与 `fade_signals`/`s_risk`，情绪侧退潮用 `mood` 的炸板率/连板高度交叉印证）」；个股须答「剩余空间（`space`：异动偏离、连板高度 → 是否还有 b 点）」与「该低吸还是追高（引 `action`，连同所在线 `s_risk` 与 regime 说明依据）」；**给出低吸/关注前**必须先看 `pullback` 并临时 `web_search` 最新逻辑面（写来源+时点，或明示缺口 → 按 A 杀风险对待）。既要写主升侧，也要写退潮侧（`boards.weak_concept`，只写相对弱势）。
13. **`strength` 与 `rot`/`hot` 并行不冲突**：三者口径不同（rot 是超额×量能分组、hot 是概念强度 Top、strength 是主题线合并 + 个股精算）。冲突时并列写出，不要择一掩盖；`strength.quote_trade_date` 可用于校验其他维度的交易日。

## 输出模板（必须遵守）

目标体量：约两屏到四屏（`## 近期强势` 与自选逐票会拉长；仍保持可扫读，忌注水）。

```markdown
## 结论
- 先写**结构 regime**：一句话（`strength.regime` 标签 + 1～2 个数字），再写情绪×风格定调（带今日关键数字）
- 主线 0～3 条：板块/ETF 名 + 至少两类独立证据；证据不足就写「暂无确认主线」
- 一句「近期强势方向」（`strength.themes`，跨行业口径；与 `## 近期强势` 呼应但不重复数字）
- 一句「今日最该警惕的点」（常含拥挤、缩量假突破、一日游）

## 依据
- 结构 / 情绪 / 风格 / 轮动 / 热点 / 拥挤 / ETF / 指数与自选涨跌（各 2～4 句，名称+数字；勿大表；结构一句引 `strength.regime`）
- **量价**：ETF 量比、watch_advice.vol_stance 可判断放缩量；**主线 ETF 必看 session_path**（高开低走/冲高回落等）；list.amount、rank 成交额只报绝对值/活跃度；无历史基准或无 OHL 写缺口
- 不含涨跌榜、不含逐票操作建议、不含底部启动/推荐关注的个股清单（见后文独立节）

## 涨跌榜
- 涨幅侧：主题簇 1～3 个（行业/概念标签聚合）+ 每簇 1～2 只代表股（名/码 + 涨跌幅；能写则带绝对成交额）
- 跌幅侧：是否成统一杀跌主线；若杂乱，写明「未见统一杀跌」
- 对照：与结论主线同向 / 背离一句；点破「价涨缩量」或「高位放量滞涨」若证据存在
- 3～6 句即可；禁止贴 Top50/20 全表

## 近期强势
- **结构 regime**：一句话，写 `strength.regime` 标签 + 1～2 个数字（5 日上涨概念占比 / Top十分位−中位数 / 涨停行业 HHI / 风格标签）
- **主题线 1～3 条**（跨行业口径，可多条板块合并成一条线）：`主题名`（含哪些板块/别名）+ 相对沪深300 超额 pp + 宽度或涨停数或量比 + 领涨股 1～2 只（名/码 + 5 日与当日涨幅）+ **加速/退潮**一句（引 `stage`、`fade_signals`/`s_risk`；退潮即提示可能已在 S 点区域）
- **个股 2～4 只**（可为自选外）：`代码 名称` + 5日/10日涨幅或超额 + 量能（`rel_vol` / `vol_stance`）+ 一句技术（均线位置 + MACD/ADX）+ 所属主题或「独立走强」+ **空间与操作**（`space`：3日偏离/连板高度 → 还有没有 b 点；`action`：低吸/追高/不参与 + 依据）+ **回落性质与逻辑面**（`pullback`；低吸/关注票另附**最新**消息面/基本面核实：来源+时点，或写缺口）
- **退潮侧 1～2 条**（`boards.weak_concept`）：只写相对弱势与跌幅，禁写「必然反转」
- **归因三层各一句**：市场因素（顶层 `market.context`：regime + 风格 + 基准）→ 主题（超额 / 宽度 / 涨停集中度）→ 个股（技术 + 量能）；只写同向或可能相关
- `score` / `turn_score` 若引用，必须写明「截面分位」，不得写成概率

## 自选操作建议
对 `watch_advice.items` 每只各写一小段（可按涨跌或原序），**七个维度 + 倾向**（缺失就写缺口，勿编造）：
- **代码 名称（涨跌%）**：
  - 技术：均线位置 + MACD/ADX 一句 + 量能（必写 vol_stance/rel_vol，有则带 amount）
  - 空间与口径：若 `strength.stocks` / `strength.bottom` 覆盖该票 → 引 `space`（异动偏离/连板 → 还有没有 b 点）、`pullback`（回落性质）、`action`（低吸/追高/不参与）；未覆盖 → 写「异动口径缺口」，禁止自行推断
  - 资金：`main_inflow` / `main_inflow_pct`（当日主力净流入与占比；未覆盖写缺口）；行业资金/龙虎榜/北向属**体系缺口**，有 `web_search` 证据才写
  - 逻辑面（最新）：**临时 `web_search`** 最新公告/业绩/催化，写来源+时点；查不到 → 写缺口并按 A 杀风险对待
  - 板块：…（行业/概念 + 当日强弱一句 + 是否属于某条强势线；线只作理由）
  - 板走势：…（用本轮 rot/hot/crowd/etf/strength 对齐；对不上写缺口）
  - 大盘：…（用本轮指数/情绪/风格锚；可对照指数涨、个股量能不能跟上）
  - 倾向：宜… / 不宜… / 优先…（量价背离时倾向偏观察；与 `action` 不一致时写明理由）
失败票：一行写明指标/归属缺失，不编造。
若 `items` 为空或 `errors` 含 `watchlist:empty`：本节只写一句「自选为空/取证失败」，勿编造个股。

## 风险
- 3～5 条可验证风险（拥挤分位、退潮残留、风格背离、数据缺口）

## 操作建议
- 3～5 条全市场层面的「宜 / 不宜 / 优先」行为倾向（与上一节自选逐票区分开）
- 禁止：仓位%、目标价、「买入 XX」「加仓到 x 成」

## 关注建议
- 3～5 条接下来盯什么（尽量可量化/可复查）——只写**指标/条件**，禁止出现具体代码/名称清单
- 例：明日 mood 涨停是否仍 >80、炸板率是否回升；半导体拥挤分位是否自高位回落；主线量能能否续放 / 缩量一日游；自选中收于 MA20 下方的家数是否下降

## 底部启动
- 来源 `strength.bottom`（按 `launch` 启动标志加权分排序，≤10 只）；**只写票**，每只写：`代码 名称` + 位置（5/10/60 日涨幅：还低）+ `launch` 命中项（量能 rv20/rel_vol/MFI、形态 MA20/MA60/收盘位置/MACD 柱）+ 未命中项（`launch.miss`，别只报喜）+ `space`（异动空间）+ 是独立走强还是某条线的理由
- 每只必须过**最新逻辑面核实**（来源+时点）或明示缺口；无最新逻辑证据 → 按 A 杀风险对待，不得写「可参与」
- `bottom` 为空时写一句「本轮无满足启动标志的票」并说明原因（勿硬凑）

## 推荐关注
- **与 `## 底部启动` 不重复同一只票**：这里写底部启动之外的观察票（自选 / `strength.stocks` 中空间充足或「等回踩」的强势票 / 涨跌榜主线代表 / 跌侧高门槛票）
- **两节合计 0～10 只**（严格 ≤10）；默认可为 0（写「暂无明确关注票」）
- **对象必须是具体票**：板块/主题线只能作为「为何观察」的理由之一，不允许用「只跟线、不跟票」代替
- 涨侧每只四要素 + 口径：1) 为何观察（线/催化作理由）；2) 技术形态；3) 量价形态；4) 板块/概念；另附 `space`（还有没有 b 点）、`pullback`（回落性质）、`action`（低吸/追高/不参与）、`main_inflow`（主力净流入）与**最新逻辑面核实**（来源+时点，或缺口）；每只再给 **1 条可复查的触发条件**（形态/量能/资金条件，如「回踩 MA10 且缩量」「站上 MA60 且 rv20>2」；**不是点位**）
- 跌侧（默认可零，高门槛）：1) 牵动对象；2) 为何可能扩散的证据；3) 大致原因（无则必须 `web_search`，仍无写缺口）；4) 板块锚；禁止仅因跌幅大入选
- 仅有 rank、无 K 线：技术栏只能写「未取 K 线/技术缺口」，禁止用涨跌幅/成交额推断均线/MACD/ADX；量价只能写「当日成交额 X（无历史基准）」
- 表述用「观察 / 跟踪」，禁止买入、仓位%、目标价；与 `## 关注建议` 分工：本节只写具体票，关注建议只写指标与条件
```
