# omg

`omg` is a small Python command-line toolkit for tracking and reviewing A-share market data. It focuses on practical daily workflows: watchlists, market heat, announcements, industry rotation, concept strength charts, and local screening.

The project is built around public market data libraries and local files. It does not require a hosted service or account credentials.

## Features

- Query a local watchlist.
- Review hot market concepts and industry rotation.
- Read stock announcements.
- Plot concept strength curves for one or more concepts.
- Run local screening helpers.
- Sync a watchlist section to another local text file through an explicit target path.

## Installation

```sh
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -e .
```

`TA-Lib` may require native dependencies on some systems. Install the system package first if pip cannot build it.

## Usage

```sh
omg list
omg hot
omg notice
omg rot
omg filter
omg -k 半导体 人工智能
```

To sync the `# 自选` section from `stocks/my_list.txt` to another local file:

```sh
export OMG_COPY_TARGET_PATH=/absolute/path/to/holdings-watchlist.txt
omg copy
```

`stocks/my_list.txt`, the generated SQLite database, and local check files are intentionally ignored by git because they are personal/local runtime data.

## Data

The toolkit uses the Python dependencies listed in `requirements.txt`, including `adata`, `pandas`, `matplotlib`, `pypinyin`, and `TA-Lib`. Local derived data is stored under `stocks/` and can be regenerated by the tool.

## Project Status

This is an early personal workflow tool that is being prepared for public open-source use. The current API and command output may change as the project becomes more documented and tested.
