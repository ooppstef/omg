# omg mood + omg style 设计

## 目标

两个独立 CLI 命令，解释 A 股「情绪周期」与「风格结构」。输出：结论块 → 当日指标表 → 近 N 日趋势表。结论准确性优先于速度。

## 数据

| 命令 | 源 | 说明 |
|------|-----|------|
| `omg mood` | akshare 东财涨停四池 | `stock_zt_pool_em` / `_zbgc_em` / `_dtgc_em` / `_previous_em`（维护走库，业务不绑裸 HTTP） |
| `omg style` | adata 指数日线 | 沪深300 `000300`、中证1000 `000852`、科创50 `000688`、红利指数 `000015` |

默认回看 `N=8` 个交易日（`OMG_MOOD_DAYS` / `OMG_STYLE_DAYS`）。

## mood 阶段（互斥，按优先级）

输入特征：涨停数、跌停数、炸板数、炸板率、连板高度、首板占比、昨日涨停今日均涨跌（溢价）、涨跌家数比（若可得）。

优先级（互斥）：

1. **退潮**：跌停≥30 或（涨停&lt;30 且炸板率&gt;50%）或 溢价≤-5%
2. **冰点**：涨停&lt;30（须在炸板率分歧之前，避免冷市被标分歧）
3. **分歧**：涨停≥30 且炸板率 30%–50%，或 高位弱高度+跌停抬升，或 中位跌停抬升
4. **主升**：涨停≥60 且 高度≥5 且 炸板率&lt;30% 且 跌停&lt;10
5. **修复**：涨停 30–60、跌停&lt;10、炸板率中低、高度 2–4
6. **中性**：其余

理由必须带关键数字。当日涨停/跌停/炸板皆空则数据不足，不硬判。

## style 状态（可并列主标签 + 辅标签）

相对收益窗口：5 / 20 日；辅看 60 日。

- **科技虹吸**：科创50 相对沪深300 的 5 日与 20 日超额均明显为正，且显著强于红利
- **小盘占优**：中证1000 − 沪深300 超额占优
- **大盘占优**：沪深300 − 中证1000 超额占优
- **红利防守**：红利相对沪深300 占优，且科技/小盘偏弱
- **均衡扩散**：上述两两超额绝对值都小

结论一行主状态 + 3–5 条数字理由；表内给出各指数涨跌与相对差。

## 非目标

无 `omg pulse` 汇总、无图表、无交易/回测、不改动既有 `crowd` HTTP。
